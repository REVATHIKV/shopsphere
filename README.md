# ShopSphere — E-commerce Management System

A portfolio project built with Laravel and MySQL to demonstrate practical PHP development skills.

## Features
- Product creation, listing, editing and deletion
- Server-side validation and unique SKU enforcement
- Inventory stock tracking
- Dynamic dashboard metrics
- Automated feature tests

## Tech Stack
- PHP
- Laravel
- MySQL
- Blade
- Bootstrap
- PHPUnit / Laravel testing tools

## Getting Started
1. Clone the repository.
2. Install dependencies using `composer install`.
3. Configure the local `.env` file and database credentials.
4. Create the database and run `php artisan migrate`.
5. Start the application with `php artisan serve`.

## Run Tests
Run `php artisan test` using the project's dedicated test database configuration.
